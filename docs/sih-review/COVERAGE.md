# SIH26182 — Requirement Coverage Matrix

Every requirement in the problem statement (`PS_SIH26182.md`) mapped to the code as it stands on **2026-09-27** (branch `main` + the uncommitted working tree). Evidence is `file:line` in this repo. Where behaviour was checked by running the code, the run is named (see REVIEW.md §1.1 for exactly what was run).

## Rating rules (strict)

| Status | Meaning |
|---|---|
| **Done** | Working logic exists and was exercised (by tests or a live run). Known defects are listed but do not negate the feature. |
| **Partial** | Some working logic, but a material piece of the requirement is absent, or the UI promises more than the logic delivers. |
| **Mocked** | The flow exists but its essential external effect is simulated or hand-entered. |
| **Missing** | No implementation. |

**Compulsory** = the PS's "The system should…" items (including each "support identification of…" item) and every "Expected Solution" item. **Optional** = "The system may additionally support…".
